- Tutorial de uso:
1. Ir a Maven y ejecutar `clean compile package` para generar el archivo `billetera-digital.war`.
2. Crear y configurar un servidor con **Apache Tomcat**.
3. Desplegar el archivo `billetera-digital.war` en el servidor.
4. Acceder desde el navegador a: `http://localhost:8080/billetera-digital/`
